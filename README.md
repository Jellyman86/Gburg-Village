# Gburg Village

A humorous family/neighborhood top-down adventure in HTML Canvas — Final Fantasy IV–VI presentation, Zelda-style real-time exploration and dinosaur combat. No build step; open the page and play.

**Play the current version (V8 · Island Skies):** https://jellyman86.github.io/Gburg-Village/v8/

## Developing

```powershell
npm install
npm run test:quick      # ~30 s check for routine changes
npm run serve           # local preview at http://127.0.0.1:5180/v8/
npm run tasks           # list every task
```
